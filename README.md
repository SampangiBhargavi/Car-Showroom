# 🚗 DriveX Motors – Car Showroom Website

DriveX Motors is a responsive web-based car showroom application developed to provide users with an easy way to explore cars, brands, offers, services, and book test drives online.

## 📌 Project Overview

The website allows customers to:

* Browse available cars
* Search and filter cars
* Explore cars by brand
* View car services
* View car gallery
* Check available offers
* Book a test drive
* Use customer login
* Use admin login
* Manage vehicle information through the admin dashboard

The project uses **LocalStorage** to store vehicle, offer, and test-drive booking data without requiring a backend database.

## 💾 Data Storage

This project uses **Browser LocalStorage** instead of a traditional backend database.

The following information can be stored:

* Vehicle details
* Offers
* Test-drive bookings
* Login status
* Admin session information

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in **Visual Studio Code**.
3. Make sure Bootstrap files are available in the `node_modules` folder.
4. Open `index.html` using a browser or VS Code Live Server.
5. Explore the DriveX Motors website.
